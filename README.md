# Blue Steal (macOS)

Scans and displays BLE advertisement beacons associated with FIDO CTAP 2.2 hybrid tunnel specification.

Pairs cross-platform with the `bluesteal-windows` companion app over a public MQTT broker + WebRTC data channel. To port to another platform (Linux, iOS, Android, Web, …) so it interoperates with the existing macOS and Windows clients, see [docs/PORTING_GUIDE.md](docs/PORTING_GUIDE.md).
